# Halka Hızlı Liste

iPhone için soldan açılan checklist (sidebar) web uygulaması.

- Görev ekle, tamamlandı olarak işaretle, düzenle veya sil.
- Tarih/saat belirle veya daha sonra seç.
- Veriler yalnızca cihazda saklanır; yedek alma/yükleme kullanılabilir.
- iOS'ta sidebar sadece uygulamanın içinde çalışır, diğer uygulamaların üstüne çıkamaz.

Yayımlamak için GitHub Pages ayarlarında main dalının kök dizinini seçin.
